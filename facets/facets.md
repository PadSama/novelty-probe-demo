# 想法拆解（facets）

> 来源：`idea/idea.md`（原文未改动）。本文件只拆解想法、设计检索词：不判断新颖性，不列文献。

**想法原文**：我注意到身边越来越多人用 AI 做研究。我想研究：科研人员使用 AI 工具，会不会让整个学科的选题变窄？打算用大规模论文数据来测。

## 总览

| # | 面 | key（queries.json 用） | 想法中对应的内容 |
|---|---|---|---|
| F1 | 研究问题 | `research_question` | 科研人员使用 AI 工具 → 学科层面的选题范围是否收窄 |
| F2 | 作用机制 | `mechanism` | AI 使用通过什么途径影响选题（原文未说明，下面列的是候选机制） |
| F3 | 研究情境 | `context` | 谁在用（科研人员）、用什么（AI 工具） |
| F4 | 数据与方法 | `data_method` | 大规模论文数据：怎么测 AI 使用、怎么测选题范围、怎么做因果识别 |
| F5 | 预期发现 | `expected_findings` | 学科选题变窄（另加一个反向结果词，避免只找支持证据） |

类型标注：**核心** = 想法本身的说法；**同义** = 同一概念的其他说法；**相邻学科** = 其他学科对同一或相近概念的叫法；**上位** = 范围更宽的概念；**反向** = 与预期相反的结果。⚠ = 检索时容易混入的同名概念。

---

## F1 研究问题 `research_question`

自变量是科研人员使用 AI 工具，因变量是学科层面的选题范围。个人的选题（微观）汇总成学科的选题分布（宏观），所以两个层次都要有检索词。

| # | 检索词 | 类型 | 说明 |
|---|---|---|---|
| 1 | "AI in science" | 核心·自变量 | |
| 2 | "research topic selection" | 核心·因变量（个人层） | 对应"选题" |
| 3 | "problem choice" | 同义·相邻学科（科学社会学） | 科学社会学对"选题"的惯用说法 |
| 4 | "topic diversity" | 核心·因变量（学科层） | ⚠ NLP 中也指主题模型的评价指标，需与科研情境词组合 |
| 5 | "direction of science" | 相邻学科（创新经济学） | 来自"rate and direction"传统：某种技术是否改变研究方向 |

## F2 作用机制 `mechanism`

想法原文没有说明机制。下面五个是从想法推出的候选机制，只用于检索；是否成立要看文献证据。

| # | 检索词 | 类型 | 说明 |
|---|---|---|---|
| 1 | homogenization | 核心 | 大家用同一类模型，产出趋同（HCI/NLP 常用词）；检索式中写作 homogeniz* / homogenis*。⚠ 材料、力学中有同名概念 |
| 2 | "algorithmic monoculture" | 同义（系统层）·相邻学科（计算机科学） | 大量使用者依赖同一模型，判断彼此相关 |
| 3 | "streetlight effect" | 相邻学科（科学哲学/经济学） | 研究向数据和工具好用的问题集中 |
| 4 | "exploration-exploitation" | 相邻学科（组织学习/管理学） | 工具提高"利用"已知方向的回报，挤出"探索"。⚠ 强化学习中有同名概念 |
| 5 | "Matthew effect" | 相邻学科（科学社会学） | AI 检索和推荐放大高被引文献，注意力更集中 |

## F3 研究情境 `context`

| # | 检索词 | 类型 | 说明 |
|---|---|---|---|
| 1 | "large language models" | 核心 | 生成式 AI 时代的主要工具 |
| 2 | "generative AI" | 同义 | |
| 3 | "machine learning" | 上位 | 覆盖"AI 作为研究方法"这一理解。⚠ 范围很宽，噪声大 |
| 4 | "AI for science" | 相邻学科（AI 与自然科学社区） | |
| 5 | scientists | 核心·使用者 | 检索式中写作 scientist* |

**待研究者确认**："AI 工具"是只指生成式 AI（2022 年底以后），还是也包括作为研究方法的机器学习、深度学习？两种理解的时间窗不同，"AI 使用"的测法也不同。目前的检索词两种都覆盖。

## F4 数据与方法 `data_method`

分三个子问题：怎么识别论文用了 AI（测自变量）、怎么测学科选题范围（测因变量）、怎么做因果识别。

| # | 检索词 | 类型 | 说明 |
|---|---|---|---|
| 1 | "science of science" | 核心（领域名） | |
| 2 | bibliometrics | 同义（情报学/科学计量学） | 检索式中写作 bibliometric*。⚠ 与 AI 词组合时会带出大量"某领域的文献计量综述" |
| 3 | "topic modeling" | 核心·测因变量 | |
| 4 | "LLM-generated text" | 核心·测自变量 | 在大规模论文中识别 LLM 使用 |
| 5 | "difference-in-differences" | 相邻学科（计量经济学）·因果识别 | |

## F5 预期发现 `expected_findings`

想法预期的方向是"选题变窄"。第 5 个词是反向结果，用来同时找到不支持这一预期的证据。

| # | 检索词 | 类型 | 说明 |
|---|---|---|---|
| 1 | "narrowing of science" | 核心 | |
| 2 | "topic concentration" | 同义（科学计量学） | |
| 3 | "collective diversity" | 相邻学科（创造力研究） | 群体层面的产出多样性，区别于个人层面 |
| 4 | disruptiveness | 相邻学科（创新研究） | 相邻的结果构念（颠覆性），不等同于选题范围 |
| 5 | "research diversification" | 反向 | 选题变宽 |

## 附：检索式约定（`queries/queries.json`）

- 检索式只用上面表里的词，只加词尾截断（*）和英式拼写变体（homogenis*）。
- 写法是通用布尔式：引号 = 短语，* = 词尾截断，AND / OR / 括号。执行时再转换成各数据源的语法。
- `purpose` 取值：
  - **component**：想法的某个组成部分（某个机制或某个结果），不限情境。
  - **application**：同一关系或机制放在科研情境里。
  - **method**：可借用的数据与方法（测 AI 使用、测选题、因果识别）。
  - **concurrent**：近期同题工作，含预印本；执行时按年份过滤（默认 2023 年起，可调）。

| id | purpose | 查什么 |
|---|---|---|
| Q1 | component | 生成式 AI 是否让产出趋同（机制），不限于科研 |
| Q2 | component | 论文数据中学科选题收窄或变宽的证据（结果），不限原因 |
| Q3 | application | AI 使用与科研人员选题、研究方向的关系 |
| Q4 | application | 路灯效应、马太效应、探索–利用等机制在 AI 辅助科研中的证据 |
| Q5 | method | 识别论文中的 LLM 使用、测选题、因果识别的方法 |
| Q6 | concurrent | 近期直接检验"AI 与科研选题多样性"的工作 |
